## Overview
**Ryujinx Emulator** is a powerful open-source Nintendo Switch emulator. It allows you to play your favorite Switch games on PC with high accuracy, great performance, and regular updates. Known for its excellent compatibility and stability.

> [!Important]
> This emulator is for educational and game preservation purposes only. You must legally own the original Nintendo Switch game files (dumps) to use them.

## Installation
### For Regular Users
1. Download and extract the archive
2. Run `Ryujinx.exe`
3. Add your legally dumped Nintendo Switch games
4. Configure graphics, controls and audio settings
5. Start playing

## Troubleshooting
| Problem                    | Solution                                      |
|----------------------------|-----------------------------------------------|
| Emulator doesn't start     | Run as Administrator                          |
| Low FPS                    | Lower resolution or enable Vulkan             |
| Game crashes               | Update GPU drivers and verify game files      |
| Antivirus warning          | Add the folder to exclusions                  |
| Black screen               | Switch between OpenGL and Vulkan backend      |
| Controller not working     | Configure input settings                      |
